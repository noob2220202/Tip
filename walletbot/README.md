# walletbot — 지갑 입금 알림·시세 봇

TRON 지갑(사용자당 최대 3개)에 **USDT(TRC20)·TRX가 입금되면 알려 주고**, 잔액을 원화로 환산해 보여 주고, 빗썸 USDT 시세와 **김프**를 조회·알림하는 봇입니다. 여러 사용자가 같이 쓰는 일반 봇이고, 채널 가입 게이트는 공통 `run_bot`이 붙입니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| 💼 지갑 | TRON 주소(체크섬 검증)를 3개까지 등록. 별명, 삭제 가능. 등록한 시점 이후 입금만 알린다 |
| 📥 입금 알림 | TronGrid에서 **확정된** 입금(USDT, TRX)만. 보낸 주소·금액(+원화)·시각(KST)·TRONSCAN 링크 |
| 🧹 소액 필터 | 최소 알림 금액(USDT·TRX 따로, 기본 0.1). 주소 위장용 소액 스팸 입금을 거른다. 1 미만 입금에는 경고를 붙인다 |
| 💰 잔액 | 지갑별·합계 USDT, TRX와 빗썸 시세 기준 원화 환산 |
| 📈 시세 | 빗썸 USDT/KRW·TRX/KRW, 기준 환율(USD/KRW), 김프(%) |
| 📉 김프 조건 | "N% 이상/이하가 되면 알림". 최대 3개. 한 번 울린 뒤 0.2%p 되돌아가야 다시 울린다 |
| 🕘 정기 시세 | 정한 시각(KST, 최대 3개)에 시세 전송. 정한 시각에서 10분 안이면 늦게라도 보낸다 |

명령어: `/지갑` `/잔액` `/시세` `/알림` `/설정`, 영문 `/wallet` `/balance` `/price` `/alerts`, `/menu` `/help` `/cancel`. 모든 기능은 버튼으로도 쓸 수 있다.

## 시세 출처

- **빗썸**: `GET /v1/ticker?markets=KRW-USDT,KRW-TRX`
- **기준 환율**: 무료 환율 API(`open.er-api.com`)의 USD/KRW. 구글에는 공식 API가 없어서 이쪽을 쓴다.
- **김프** = 빗썸 USDT 가격 ÷ 기준 환율 − 1. USDT 1개를 1달러로 계산하므로 실제 USDT/USD 시세와는 소수점 차이가 날 수 있다.
- 시세는 10초 캐시한다. 빗썸 조회가 실패하면 10분 안의 마지막 값을 "조회 지연"으로 표시하고, 환율만 실패하면 시세는 보여주되 김프는 계산하지 않는다.

## 동작 규칙

- 지갑 하나당 60초마다 USDT·TRX 두 번 조회한다(`POLL_SECONDS`). 같은 주소를 여러 사람이 등록해도 **한 번만** 조회한다.
- 조회 위치는 주소별로 저장하고 15분씩 겹쳐 조회한다. 같은 입금은 `notified` 표로 막아서, 겹쳐 조회하거나 재시작해도 두 번 알리지 않는다.
- 조회가 실패하면 조회 위치를 넘기지 않아서 다음 조회 때 놓친 입금을 알린다. 알림 전송이 일시적으로 실패하면 기록을 지워 다음에 다시 보낸다.
- 429(호출 한도)를 받으면 30초 쉬고 관리자에게 알린다(30분에 한 번). 조회 실패도 같은 방식으로 관리자에게 알린다.
- 봇을 막은 사용자는 비활성 처리해서 조회·발송 대상에서 뺀다. `/start`를 다시 보내면 되살아난다.
- TRX는 일반 전송(`TransferContract`, 성공)만 입금으로 본다. 스마트 컨트랙트 호출이나 실패한 거래, 위조 토큰은 무시한다.

## 운영 한도

TronGrid 무료 키는 하루 약 10만 요청이다(가입 화면에서 확인). 지갑 하나가 하루 약 2,900 요청을 쓰므로 **전체 약 30개 주소**가 한계다. `MAX_WALLETS_TOTAL`(기본 30)로 상한을 두고, 넘으면 새 지갑 등록을 막는다. 이미 지켜보는 주소는 자리를 쓰지 않는다. 공개 범위를 넓히려면 키를 유료로 올리거나 `POLL_SECONDS`를 늘린다.

## 설치

```bash
cd /root/walletbot && cp .env.example .env && nano .env
```

| 변수 | 설명 |
| --- | --- |
| `BOT_TOKEN` | BotFather 토큰 |
| `ADMIN_IDS` | 관리자 ID. 오류 알림을 받는다 |
| `TRONGRID_API_KEY` | TronGrid 키 (없어도 되지만 한도가 매우 낮다) |
| `MAX_WALLETS_TOTAL` | 서버 전체 주소 상한. 기본 30 |
| `POLL_SECONDS` | 지갑 조회 간격. 기본 60, 최소 15 |
| `BITHUMB_URL`, `FX_URL` | 시세 출처 주소(기본값 사용 권장) |
| `VERIFY_SECRET` | 채널 가입 검수 비밀값 |

배포는 `bash /root/Tip/scripts/deploy.sh`.

## 테스트

cd walletbot && python3 -m pytest
