# rankbot — 채팅 순위 봇 메이커

사용자가 **자기 봇 토큰을 넣어 나만의 채팅 순위 봇을 만드는** 서비스입니다. 만들어진 봇은 그룹의 채팅 횟수를 세고, 정해둔 요일·시간에 순위를 발표하고, 카운트를 0으로 초기화합니다.

관리 봇 하나(pm2 앱 `rankbot`)가 토큰을 받으면, 같은 프로세스 안에서 그 토큰의 고객 봇이 바로 폴링을 시작합니다. 서버를 다시 켜면 DB에서 모두 복구합니다.

## 사용자 흐름 (관리 봇 DM)

1. BotFather에서 `/newbot` 으로 봇을 만들고 토큰을 받는다.
2. 관리 봇에서 **➕ 봇 만들기** → 토큰을 보낸다. 토큰 메시지는 지워지고 DB에는 암호화해 저장된다.
3. BotFather `/setprivacy` → 내 봇 → **Disable** (또는 그룹에서 봇을 관리자로 지정). 안 하면 일반 채팅이 집계되지 않는다. 관리 봇이 `getMe`로 확인해서 켜져 있으면 경고한다.
4. 봇을 그룹에 초대한다.
5. **🤖 내 봇**에서 설정을 바꾼다.

## 주인이 바꿀 수 있는 값 (봇 단위)

| 항목 | 기본값 | 비고 |
| --- | --- | --- |
| 카운트 최소 글자 | 5 | 1~100. 이 글자 수 이상인 텍스트·사진 설명 1건 = 1카운트 |
| 자동 발표 | ON | 끄면 발표 없이 계속 누적. 다시 켜면 다음 일정부터 |
| 발표 요일 · 시간 | 월요일 21:00 (KST) | `21:00`, `오후 9시`, `9시 30분` 형태로 입력 |
| 봇 이름 | BotFather 이름 | `setMyName`으로 실제 봇 이름이 바뀐다. 텔레그램이 잦은 변경을 제한하면 안내한다 |
| 경품 | 없음 | 1등부터 한 줄에 하나(최대 10줄). 없으면 순위만 발표 |
| 응모 자격 | 0 (제한 없음) | 경품이 있을 때, 이 횟수 이상인 사람만 수상 |

일정을 바꿔도 이번 회차 카운트는 유지되고 다음 발표부터 새 일정이 적용된다.

## 고객 봇 명령어 (그룹)

`/순위` `/내기록` `/규칙` `/명령어` (영문 `/rank` `/me` `/rules` `/help` 도 같음). 방장·봇 주인 전용 `/집계`(중간 발표, 초기화 없음) `/상태`는 일반 유저가 입력해도 아무 반응이 없다.
텔레그램은 `/` 뒤 영문·숫자만 명령어로 쳐서, 한글 명령어는 정규식으로 잡는다(자동완성 목록에는 안 뜬다).

## 동작 규칙

- 순위는 횟수가 많은 순, 같으면 먼저 달성한 사람이 위. 그룹별로 따로 집계한다.
- 발표는 30초마다 확인한다. 시각이 된 봇은 **회차를 넘기면서 발표할 그룹을 큐에 넣는다**(한 트랜잭션). 보내기에 실패하면(429 등) 큐에 남아 다시 시도하고(최대 5번), 재시작해도 사라지지 않는다.
- 꺼져 있던 동안 시각이 지났으면 재가동 후 **한 번만** 발표한다.
- 이번 회차에 채팅이 없는 그룹은 발표하지 않는다. 강퇴당한 그룹은 비활성 처리한다.
- 토큰이 폐기되면(401) 그 봇만 멈추고 주인에게 알린다. 15분마다 `getMe`로 점검하고, 주인은 **🔑 토큰 교체**로 되살린다.
- 시간은 한국시간(UTC+9 고정)이다. 서버 시간대와 상관없다.
- 고객 봇은 한 프로세스에서 롱폴링한다. 수십 개까지는 무리가 없고, 수백 개 규모가 되면 프로세스를 나눠야 한다.

## 설치

```bash
cd /root/rankbot && cp .env.example .env && nano .env
python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"   # → TOKEN_KEY
```

| 변수 | 설명 |
| --- | --- |
| `BOT_TOKEN` | 관리 봇 토큰 |
| `ADMIN_IDS` | 관리자 ID. 봇 개수 제한을 받지 않는다 |
| `TOKEN_KEY` | 고객 토큰 암호화 키. **한 번 정하면 바꾸거나 잃어버리면 안 된다**(바꾸면 저장된 토큰을 못 푼다). `.env`와 `data/bot.db`는 서버 밖으로 나가지 않게 관리한다 |
| `MAX_BOTS_PER_USER` | 사용자당 봇 수. 기본 3 |
| `VERIFY_SECRET` | 채널 가입 검수 비밀값(관리 봇에만 게이트가 붙는다) |

배포는 `bash /root/Tip/scripts/deploy.sh`.

## 테스트

```bash
cd rankbot && python3 -m pytest
```
