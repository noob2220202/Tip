# 봇 문체·서식 가이드

모든 봇의 사용자 노출 문구는 이 규칙을 따른다. 목표는 "AI가 만든 티가 나지 않는 것", 즉 사람이 운영하는 봇처럼 읽히게 하는 것이다.

## 구조

- `shared/core/style.py`: 서식 헬퍼. 기본 `parse_mode=HTML`이며 `b`, `i`, `u`, `s`, `blockquote`, `code`, `tg-spoiler`를 지원한다. 사용자 입력은 자동으로 이스케이프한다.
- `shared/core/texts.py`: 공통 안내문(게이트, `/start`, 오류, 브로드캐스트 플로우)을 모아 둔다.
- `<봇>/bot/texts.py`: 같은 키를 덮어써서 이 봇의 말투를 바꾼다.
- 같은 상황에는 문구 2~3개 중 무작위로 하나를 골라 답이 기계적으로 반복되지 않게 한다.
- 긴 답장 전에는 `typing` 액션을 잠깐 보낸다.
- 다른 봇을 새로 만들 때도 문구는 이 규칙대로 쓴다.

## 문체 규칙

> **kakao 봇은 예외다.** `kakao/bot/texts.py`에서 공적인 말투(합쇼체)로 쓰고, 이모지·굵게·인용·코드·링크를 적극적으로 쓴다. 시작·도움말은 길고 자세하게 쓴다. 아래 규칙은 다른 봇의 기본값이다.

- 기본은 해요체(친근한 존댓말)로 쓰고, 짧게 끊는다. 반말·격식체가 필요하면 봇별 `texts.py`에서 바꾼다.
- 쓰지 않는 표현:
  - "저는 AI 어시스턴트입니다", "도움이 되었길 바랍니다", "무엇을 도와드릴까요?"
  - "~해 보세요!"처럼 느낌표를 남발하는 문장
  - 모든 내용을 번호 목록으로 나열하는 습관
  - "안내드립니다", "~하실 수 있습니다" 같은 공문 투
- 오류도 사람이 말하듯 쓴다. 예: "잠깐 꼬였어요. 다시 한 번만 눌러줘요 🙏"
- 이모지는 문장 앞이나 끝에 한 개 정도로 절제한다. 메시지당 3개를 넘기지 않고, 문장마다 붙이지 않는다.

## 서식 규칙

| 서식 | 쓰는 곳 |
|---|---|
| **굵게** | 핵심 키워드와 숫자에만 쓴다. 문장 전체를 굵게 하지 않는다. |
| *기울임* | 부연 설명과 뉘앙스에 쓴다. |
| <u>밑줄</u> | 꼭 눌러야 하는 것(버튼 안내, 기한)에만 쓴다. |
| 인용(blockquote) | 공지, 규칙, 광고 본문 요약 같은 덩어리 정보를 묶을 때 쓴다. 긴 인용은 expandable(접힘)로 쓴다. |
| `code` | 명령어와 ID에 쓴다. |
| 스포일러 | 이벤트나 정답 공개에만 쓴다. |

## 적용 예시

- 가입 안내: "채널 두 곳만 먼저 눌러주세요 👇 ‘가입했어요’ 누르면 바로 이어서 할게요."
- `/start`: 사용자 이름을 넣고 두세 줄로 끝낸다.
- 관리자 `/stats`: 표 대신 짧은 줄과 굵은 숫자로 보여준다.
- 브로드캐스트 미리보기: 실제 수신 화면과 같은 렌더링으로 보여주고, 대상 수와 서식 팁을 한 줄로 안내한다.
